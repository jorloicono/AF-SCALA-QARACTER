# AF-SCALA-QARACTER

**Duration:** 20 Hours

**Level:** Intermediate (Assumes basic programming knowledge)

---

## 1. Introduction to Scala

* **Paradigm Fusion:** Understanding the blend of Functional and Object-Oriented programming.
* **Environment Setup:** Installing Scala, **sbt** (Scala Build Tool), and IDE configuration (IntelliJ or VS Code with Metals).
* **Project Anatomy:** Overview of a standard project structure.
* **Syntax Basics:** Basic types, `val` vs `var`, and the power of type inference.

## 2. Functions & Functional Programming

* **The Functional Core:** Defining pure functions and side-effect-free code.
* **Advanced Functions:** Higher-order functions (HOFs), closures, and currying.
* **Immutability:** Why and how to stay immutable.
* **Pattern Matching:** Going beyond "switch" statements with advanced extractors.

## 3. Collections & Data Structures

* **Standard Library:** Deep dive into `List`, `Seq`, `Vector`, `Map`, and `Set`.
* **Transformations:** Mastery of `map`, `flatMap`, `filter`, `fold`, and `reduce`.
* **Performance:** Understanding lazy collections and `View`.
* **The "No-Null" Policy:** Functional error handling using `Option`, `Either`, and `Try`.

---

## 4. Object-Oriented Programming in Scala

* **Class Basics:** Classes, singleton objects, and companion objects.
* **Modular Design:** Traits, mixins, and "stackable" behaviors.
* **Data Modeling:** **Case classes** and their role in domain-driven design.
* **Polymorphism:** Standard inheritance vs. trait composition.

## 5. Advanced Functional Programming

* **Partial Functions:** Handling defined inputs.
* **Implicits:** Implicit parameters, conversions, and resolution rules.
* **Abstraction:** Introduction to Type Classes and Higher-Kinded Types.
* **The M-Word:** Understanding **Monads** through practical, real-world usage.

## 6. Concurrency & Parallelism

* **Asynchronous Code:** Working with `Futures` and `Promises`.
* **Reactive Principles:** Non-blocking I/O and backpressure.
* **Actor Model:** Introduction to **Akka/Pekko** (Actors, messaging, and supervision strategies).

---

## 7. Working with Files, APIs & JSON

* **Persistence:** File I/O operations.
* **Web Services:** Building HTTP clients/servers (Akka HTTP or sttp).
* **Data Interchange:** JSON serialization and deserialization using **Circe** or Play JSON.

## 8. sbt & the Scala Ecosystem

* **Build Definitions:** Configuring `build.sbt`.
* **Dependency Management:** Adding libraries, managing resolvers, and plugins.
* **CI/CD Basics:** Packaging and publishing artifacts.

## 9. Testing in Scala

* **Frameworks:** Writing tests with **ScalaTest** or **MUnit**.
* **Testing Styles:** Unit testing vs. Property-based testing (ScalaCheck).
* **Mocking:** Isolating components for robust test suites.

---
